# 链路 UI 与绑定

## 进度补充（2026-08-30）

绑定新增“链路入口组”（`ProxyChainBinding.entryGroups`）：用户显式选择哪些 Profile 策略组
暴露该链，组装时把生成的链 selector 追加到这些组的成员末尾，组首成员不变，原 Profile 选择保留。
编辑器新增编译预览（路径数与诊断）与保存前的警告确认。详见 [修复记录](fixes-2026-08-30.md) R4、R5。

## 目标

提供全局链路编辑、路径预览、Profile 绑定和默认链设置；操作结果全部进入单 Core 配置。

## 输入

- 链路 DAO、节点/组选择数据、编译诊断。

## 输出

- Profiles 页“链路”分栏。
- 链路列表、拖拽 hop 编辑器和 target picker。
- 分支矩阵、warning 确认、error 展示、绑定与默认开关。

## 依赖

Task 02、11。

## 实现边界

- hop 可选择节点、全局组、当前 Profile 组或本地 SOCKS/HTTP/HTTPS 端点。
- 编辑器以“客户端 → 前置 → 主节点 → 后置 → 目标”展示顺序；保存顺序直接传给编译器。
- 本地端点表单只保存连接参数和可选认证，不管理外部端点进程。
- 保存前实时展示路径数量和诊断。
- Profile 默认链只改变生成链组的默认选择，不改写源 Profile 当前组。

## 验收标准

- 可创建、复制、重命名、删除和重排链路。
- error 状态的链路不会应用到运行配置。
- 多个 Profile 可绑定同一条全局链。
- 选择单节点或单 hop 链时不增加额外运行时进程；链路切换只触发最终配置更新。

## 测试

采用编译器核心测试和手工 UI 验收，不新增 widget 测试文件。
