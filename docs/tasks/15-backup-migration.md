# 备份、恢复与数据迁移

## 目标

把节点、链路和资产纳入现有备份恢复流程。

## 输入

- schema v3 数据库。
- 旧版和新版备份 ZIP。
- 节点资产目录。

## 输出

- 扩展后的 `MigrationData`。
- DB snapshot 一致性处理。
- 节点资产归档、路径校验和恢复复制。

## 依赖

Task 03、08。

## 实现边界

- 旧备份缺少新表时按空集合恢复。
- 新备份同时包含数据库、配置、Profile、脚本和节点资产。
- 恢复前校验 ZIP 路径、manifest 和资产哈希。

## 验收标准

- v2 备份在 v3 应用恢复后保持旧数据。
- v3 备份恢复后节点绑定、链路顺序、overlay 和资产一致。
- 恢复失败不替换现有有效数据。
